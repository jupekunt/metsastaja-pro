# Metsästäjä Pro

Metsästäjän maastokartta ja jahtipäiväkirja selaimeen ja puhelimeen: jahdin tallennus, karttamerkinnät, metsästysalueet rajavaroituksella, saaliit ja havainnot.

Avaa: https://jupekunt.github.io/metsastaja-pro/

Kaikki omat tiedot pysyvät laitteen selaimessa. Sovellus on muistiinpanojen ja suunnistuksen apu: se ei korvaa karttaa ja kompassia eikä tiedä metsästysaikoja, lupia tai alueiden todellisia rajoja.
